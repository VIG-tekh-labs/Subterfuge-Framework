# Subterfuge

> **Modernization in progress — 8 October 2026.**

This fork is being maintained to restore usability on current Python environments, replace obsolete installation and update mechanisms, and add supported network assessment features.

**This development version is not yet a functional, validated application. No modern release has been published.**

The latest maintenance checkpoint adds documentation and comment-only markers; it introduces no functional changes. The modern runtime draft is not yet included on `master`.

## Current status

- The initial compatibility audit is complete.
- A Python 3 core, command-line interface and local dashboard have been drafted in a development working copy.
- The draft includes network inventory, ARP capture analysis and JSON reports.
- Initial Python syntax and synthetic demo checks pass; full functional tests and installation checks are still pending.
- Historical source is preserved; full compatibility with historical features has not been established.

## Continuity

Read [ROADMAP.md](ROADMAP.md) first for the latest checkpoint, known issues and exact next action. Follow [MAINTENANCE.md](MAINTENANCE.md) when continuing development.

Work continues in this repository. No replacement repository has been created.

Contributions are welcome through issues and pull requests. Proposed changes will be reviewed and checked before being accepted into a release.
